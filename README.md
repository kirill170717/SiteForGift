# Бюро подарков

Тестовый сайт-квест для необычного вручения подарочной карты «Золотого яблока». Обычные HTML, CSS и JavaScript, без установки библиотек и без сервера приложения.

## Сценарий

1. Проверка адресата с шуточными ответами.
2. Капча настроения: выбрать все шесть качеств.
3. Проверка умения принимать подарки.
4. Сканирование сияния до 140% (без камеры).
5. Открытие хранилища по коду `0418`.
6. Ложный финал «Ошибка 418», обещание и раскрытие демо-карты.

Квест сохраняет этап в браузере. Звук включается только по нажатию кнопки. Есть мобильная версия, управление с клавиатуры, поддержка уменьшенной анимации, копирование номера и скачивание тестовой карты в SVG.

## Локальный запуск

Нужен Node.js 22 или новее. Дополнительные пакеты не нужны.

```sh
node scripts/serve.js
```

Открыть `http://127.0.0.1:4173`. Проверки: `node --test`. Сборка: `node scripts/build.js`, результат в `dist/`.

## GitHub Pages

Рабочий процесс `.github/workflows/pages.yml` проверяет проект и публикует только файлы сайта из `dist/` после обновления `main`. В Settings → Pages выбрать источник **GitHub Actions**. На GitHub Free репозиторий должен быть публичным; приватный репозиторий требует поддерживающего Pages плана.

Ожидаемый адрес: `https://kirill170717.github.io/SiteForGift/`.

## Тестовые данные и персонализация

Сумма, номер карты, PIN и код доступа находятся в `quest.js`. Тексты экранов — в `app.js`; вступление — в `index.html`; оформление — в `styles.css`. Прототип не содержит фотографий, реальных имён или реальных данных карты.

**Не помещать действующий номер карты или PIN в этот статический сайт.** Любой посетитель может прочитать исходные файлы и обойти квест. Для настоящего сертификата нужен отдельный сервер с проверкой доступа и приватным хранением данных.

Шрифты загружаются из Google Fonts; при недоступности сервиса используются системные шрифты. После загрузки страницы сам квест работает без сетевых запросов. Первое открытие и обновление страницы требуют интернета.

Демо не является официальным сайтом магазина. Все данные вымышлены, тестовая карта не подходит для оплаты.
